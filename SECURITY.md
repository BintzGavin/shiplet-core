# Security policy

## Report a vulnerability privately

Use this repository's **Security** tab and choose **Report a vulnerability** to
open a private report through GitHub Security Advisories with the maintainers. Include affected
versions, the observable impact, reproduction steps, and any suggested
mitigation that is safe to share privately.

Do not report vulnerabilities through GitHub Issues, Discussions, or pull
requests. Those are public or unsupported participation surfaces.

The maintainers will acknowledge a complete private report when it is reviewed.
No public response-time or bounty commitment is made during source preview.

## Supported versions

Only the current default branch and published release tags are evaluated during
source preview. Self-hosted deployments remain the operator's responsibility.
