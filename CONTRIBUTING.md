# Participation policy

Shiplet Core launches in source-preview participation mode.

GitHub pull requests are not an accepted contribution path. GitHub Issues are
not an accepted product-support or feedback path, and GitHub Discussions are
not an accepted roadmap or community channel. Maintainers may close unsolicited
submissions without review so the availability of a GitHub surface is not
mistaken for a supported workflow.

Outside code and product-feedback intake is intentionally deferred. If Shiplet
opens a contribution path later, it will be documented here and will not assume
that GitHub pull requests are the intake mechanism.

Security reports are different: follow [`SECURITY.md`](SECURITY.md) to report a
vulnerability privately through GitHub Security Advisories. Do not disclose a
security issue through a pull request, Issue, or Discussion.
